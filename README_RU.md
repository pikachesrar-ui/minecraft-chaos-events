## Что такое Chaos Events?

Во время активной сессии Chaos Events запускает несколько независимых систем. Большие мировые события, персональные нелетальные подлянки, викторины и пространственные обмены накладываются друг на друга и создают испытание для друзей, небольших серверов и стримов.

Мод не начинает работу сам. Оператор запускает сессию командой `/chaos start`, может заморозить все таймеры через `/chaos pause` и безопасно остановить активные механики командой `/chaos stop`.

> [!WARNING]
> Это ранняя публичная версия. Некоторые события намеренно меняют погоду, правила мира, позиции игроков, мобов и блоки. Перед игрой сделайте резервную копию важного мира.

## Возможности

- **Большие события** с таймером на полосе босса, настраиваемыми случайными перерывами и защитой от быстрых повторов.
- **Микроподлянки** для отдельных игроков с настраиваемым интервалом: мешают играть, но не рассчитаны на намеренное убийство.
- **Викторина** с настраиваемым интервалом между вопросами: 15 секунд на ответ, награды и наказания за ошибки.
- **Пространственные обмены** между игроками и измерениями, включая механику совместной активации якорей для возвращения и настраиваемый таймер планового свапа.
- **Встроенная настройка контента** через четыре книги с переключателями отдельных событий, подлянок, вопросов и типов свапа.
- **Ускорение мира** до 200 TPS с сохранением близкой к обычной скорости игроков.
- **Дополнительные катастрофы** из [Weather2](https://www.curseforge.com/minecraft/mc-mods/weather-storms-tornadoes) и [Oh My, Meteors!](https://www.curseforge.com/minecraft/mc-mods/oh-my-meteors), если эти моды установлены.
- **Необязательная интеграция с Places**: редкие неожиданные пространственные сбои могут временно отправить игрока в Places, после чего Chaos Events автоматически возвращает его точно в исходную точку. Конкретные триггеры намеренно не документируются, чтобы механика оставалась сюрпризом.
- Английская и русская локализация предметов; серверные сообщения пока преимущественно на русском языке.

## Требования

| Компонент | Версия |
| --- | --- |
| Minecraft | `1.21.1` |
| NeoForge | `21.1.244` или более новая совместимая сборка для `1.21.1` |
| Java | `21` |
| Установка | На сервер и клиент |

Weather2, Oh My, Meteors! и Places необязательны. Chaos Events автоматически проверяет наличие поддерживаемых интеграций во время работы.

## Установка

1. Установите Minecraft `1.21.1` и совместимую версию NeoForge.
2. Скачайте JAR со страницы [Releases](https://github.com/pikachesrar-ui/minecraft-chaos-events/releases) или соберите мод из исходного кода по инструкции ниже.
3. Поместите JAR в папку `mods` на сервере и у всех подключающихся игроков.
4. Запустите мир и выполните `/chaos start` с правами оператора.

## Команды

Для всех команд требуется второй уровень прав.

| Команда | Назначение |
| --- | --- |
| `/chaos start` | Запустить новую хаос-сессию |
| `/chaos pause` | Заморозить механики и все таймеры |
| `/chaos resume` | Продолжить сессию после паузы |
| `/chaos stop` | Остановить сессию и убрать временные эффекты |
| `/chaos status` | Показать состояние систем, таймеры и количество контента |
| `/chaos skip` | Завершить текущее большое событие и запустить перерыв |
| `/chaos book big` | Выдать книгу настройки больших событий |
| `/chaos book prank` | Выдать книгу настройки микроподлянок |
| `/chaos book trivia` | Выдать книгу настройки вопросов викторины |
| `/chaos book swap` | Выдать книгу настройки свапов игроков |
| `/chaos test big` | Принудительно запустить случайное большое событие |
| `/chaos test speed` | Запустить ускорение мира |
| `/chaos test prank` | Применить случайную микроподлянку |
| `/chaos test screamer` | Показать скример выбранному игроку |
| `/chaos test trivia` | Запустить вопрос викторины |
| `/chaos test swap` | Запустить обмен позициями; нужно не менее двух игроков |
| `/chaos test places` | Принудительно проверить скрытый переход в Places для выполняющего команду игрока |

## Настройка событий в игре

Оператор может получить одну из четырёх книг через `/chaos book ...` и открыть её правой кнопкой мыши. В книге отображается постраничный список с переключателями `ВКЛ`/`ВЫКЛ`, а в верхней части — минимальный и максимальный интервал запуска. Время можно вводить в формате `M:SS` или обычным количеством секунд. Кнопка **«Сброс»** возвращает стандартный диапазон, а **«Сохранить»** записывает выбор в `config/chaosevents-settings.json`.

Книга больших событий меняет паузу между окончаниями и запусками больших событий; книга микроподлянок — задержку между подлянками; книга викторины — задержку между вопросами; книга свапов — интервал автоматического планового обмена. Допустимый диапазон — от 10 секунд до 6 часов. Продолжительность самого активного большого события этими полями не меняется.

Если Chaos Events уже запущен, после сохранения текущие временные механики корректно очищаются, а внутренняя хаос-сессия запускается заново с новым набором включённого контента и новыми таймерами. Перезапуск Minecraft или сервера не требуется.

Книга свапов также позволяет независимо отключить плановый обмен, единичный свап за первую алмазную руду и большое событие «Пространственный сдвиг».

## Сборка из исходного кода

Установите JDK 21, клонируйте репозиторий и выполните:

```bash
./gradlew build
```

В Windows PowerShell:

```powershell
.\gradlew.bat build
```

Готовый JAR появится в `build/libs/`. Для разработки доступны команды `./gradlew runClient` и `./gradlew runServer`.

GitHub Actions проверяет сборку каждого коммита и pull request. Теги вида `v*` автоматически собирают проект и публикуют JAR в GitHub Releases.
