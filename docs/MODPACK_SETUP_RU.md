# Дополнения для сборки Chaos Events

Сборка рассчитана на Minecraft 1.21.1, NeoForge 21.1.244 и Java 21.

## Сохранение инвентаря после смерти

Рекомендуемый мод: **GraveStone Mod 1.21.1-1.0.37**.

- CurseForge project ID: `238551`
- CurseForge file ID: `8056307`
- имя файла: `gravestone-neoforge-1.21.1-1.0.37.jar`
- установка: сервер и все клиенты
- дополнительные зависимости: отсутствуют

При смерти мод помещает инвентарь в надгробие, возвращает предметы в исходные слоты и выдаёт
некролог с измерением и координатами. Администратор может восстановить потерянный инвентарь
командой `/restore`.

## Долгосрочные метки

В установленном **Ping Wheel** уже есть бесконечная продолжительность метки. Откройте
`/pingwheel config`, установите `Ping Duration` в крайнее правое положение `∞` (в конфиге это
`"pingDuration": 60`). Метка останется до ручного удаления, пока клиент не будет перезапущен.

Ping Wheel хранит активные метки только в памяти клиента, поэтому для точек, которые должны
переживать перезапуск игры, рекомендуется **Xaero's Minimap 26.2.0 для NeoForge 1.21.1**.
Клавиша `B` создаёт точку, `U` открывает список и позволяет поделиться точкой в чате. Для обычных
личных точек достаточно установить мод на клиенты; установка на сервер улучшает разделение точек
между мирами и измерениями.

Не кладите чужие JAR-файлы непосредственно в публичный Git-репозиторий без разрешения автора.
В экспортируемой сборке храните ссылки/идентификаторы файлов платформы, а сами JAR загружайте
официальным лаунчером.
