# Places Horror Layer

В приватной сборке Chaos Events пребывание в измерениях `places:*` может становиться заметно
тревожнее без обычных скримеров.

## Рекомендуемые дополнительные моды

Для полного набора эффектов установите на сервер/хост и на всех клиентов:

- `serversidehorror-1.21.1-neoforge-4.2.jar`
- `deimos-1.21.1-neoforge-2.7.jar`

Они являются **optional**-зависимостями Chaos Events: без них мод по-прежнему запускается, но часть
ложных звуков и шагов заменяется более простыми встроенными эффектами.

## Как работает интеграция

При старте сервера Chaos Events переводит Server-Side Horror в управляемый режим: его собственные
случайные события отключаются и он используется только как поставщик эффектов для Horror Layer.
Сам Horror Layer начинает выдавать события игрокам только во время запущенной Chaos-сессии и только
если игрок находится в измерении `places:*`.

После `/chaos stop` автономный Server-Side Horror **не включается обратно**: он остаётся заглушённым
до закрытия сервера, поэтому хоррор не начинает случайно появляться в обычном доме игроков.
Изменения делаются только в памяти текущего процесса и не переписывают пользовательский config-файл
Server-Side Horror.

**Jumpscare Server-Side Horror принудительно выключается и Chaos Events его не вызывает.**

## Возможные события внутри Places

События назначаются каждому игроку отдельно. Первый эффект обычно появляется через 12–25 секунд,
затем следующие — примерно раз в 22–48 секунд по реальному времени. Одинаковый эффект два раза
подряд не выбирается.

- ложные шаги в пустом коридоре;
- звук фальшивой добычи блоков рядом;
- редкий отдалённый тревожный звук;
- короткое мигание/провал освещения через эффект Darkness;
- случайное открытие или закрытие ближайшей двери;
- краткий силуэт в тёмной броне, который исчезает через несколько секунд или когда игрок подходит;
- очень редкий небольшой пространственный «срыв», который может разнести двух находящихся в одном
  мире Places игроков на несколько блоков/за соседнюю стену.

Частоты слегка отличаются по измерениям. Например, в `rooms_0` чаще происходят шаги, добыча и двери,
в `warp_tunnel` — звуки и мерцание, а на `red_road_dim` повышен шанс увидеть силуэт.

## Быстрая проверка

После `/chaos start` и перехода в Places оператор может вызвать одно случайное событие командой:

```text
/chaos test places horror
```

Команда работает только когда сам вызывающий игрок уже находится в `places:*`.

## Совместимость

Horror Layer срабатывает по namespace измерения, поэтому работает не только в шести мирах, которые
Chaos Events сейчас умеет выбирать для случайного переноса, но и при ручном попадании в другие
измерения мода Places (`pools_dim`, `aquarium_tunnels_dim` и т.п.).

Расписание использует wall-clock время, поэтому ивент ускорения мира на 200 TPS не превращает хоррор
в спам.
